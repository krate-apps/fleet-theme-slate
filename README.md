## Install

1. Enable the **Fleet Official** bucket (`org.fleet.official`).
2. Open **Extensions / Themes** (or Appearance) and install **`org.fleet.theme.slate`**.
3. Select **Slate** under **Settings → Appearance**.

Listing: [`fleet-official-bucket/bucket/org.fleet.theme.slate.json`](https://github.com/krate-apps/fleet-official-bucket/blob/main/bucket/org.fleet.theme.slate.json).
